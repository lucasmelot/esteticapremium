# LUMÉA — Estética Facial

Projeto demonstrativo de uma clínica fictícia de estética facial, desenvolvido em HTML, CSS e JavaScript puro e pronto para GitHub Pages.

## Estrutura

- `index.html` — conteúdo e estrutura semântica
- `css/styles.css` — identidade visual, layout e responsividade
- `js/script.js` — menu mobile, animações, depoimentos e CTAs de WhatsApp
- `assets/images/` — pasta reservada caso as imagens externas sejam substituídas por arquivos locais

## Mockup de dados

A versão atual foi tratada como um projeto real de portfólio: serviços, profissional responsável, horários, contatos, relatos e galeria estão preenchidos com dados demonstrativos. Não há áreas visuais vazias ou placeholders de imagem.

A marca LUMÉA, Helena Martins, contatos, relatos e demais informações comerciais são fictícios e existem apenas para demonstração.

## WhatsApp

O número fictício está centralizado no arquivo `js/script.js`. Substitua pelo número real antes de publicar para um cliente.

## Imagens

As imagens usam URLs externas do Unsplash. Para um projeto definitivo de cliente, recomenda-se baixar imagens autorizadas, otimizá-las em WebP/AVIF e referenciá-las localmente.

## Deploy

Pode ser publicado diretamente no GitHub Pages sem backend ou processo de build.
